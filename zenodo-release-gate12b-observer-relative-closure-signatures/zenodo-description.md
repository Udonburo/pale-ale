Observer-Relative Closure Signatures on Replay Artifact Graphs:
A Bounded Source-Facing Audit of Existing LLM Artifacts

DOI: https://doi.org/10.5281/zenodo.20080003

This bounded technical report presents Gate12B, a read-only secondary audit
over existing Gate12A/Gate12B replay artifact graphs. It reports an
archive-family closure-signature phenomenon across four dense-transformer
model lines, with source-facing queue and derived annotation evidence, while
preserving explicit boundaries: it is not a universal interpretability law,
not a model-quality benchmark, not a correctness classifier, not a
weight-level causal claim, and not a physical invariant.

Included files:

- `gate12b-observer-relative-closure-signatures.pdf`: final rendered PDF
  manuscript.
- `gate12b-observer-relative-closure-signatures.tex`: TeX manuscript source.
- `gate12b-paper-evidence-package-manifest.md`: release-facing compact
  evidence manifest derived from
  `workstream/229_GATE12B_PAPER_EVIDENCE_PACKAGE_MANIFEST.md` in the
  repository.
- `CHECKSUMS-SHA256.txt`: SHA-256 checksums for packaged files.

Generated `runs/` artifacts are intentionally not included. The manifest
records the artifact directories, manifests, checksums, row counts, and
source-linkage checks used by the manuscript tables.
