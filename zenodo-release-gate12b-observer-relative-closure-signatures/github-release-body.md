## Summary

This release packages the Gate12B manuscript and compact evidence manifest for
external archival use. Gate12B is a read-only secondary audit over existing
Gate12A/Gate12B replay artifacts. The report is artifact-bounded and does not
claim a universal interpretability law, model-quality benchmark, correctness
classifier, weight-level causal mechanism, or physical invariant.
