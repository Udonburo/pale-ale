# Outreach Memos

This directory contains outward-facing pale-ale research memos and grant/collaboration drafts.

These documents are deliberately bounded. They should not widen Gate12A or Gate12B claims, and they should not describe pale-ale as a benchmark, correctness classifier, model-quality ranking system, deception detector, or mechanistic claim about model weights.

## Files

- `common-memo-v0.4.2-validation.md`

  General one-page memo for evaluation, red-team, agent-monitoring, warm-intro, and collaboration contexts.

- `ltff-memo-v0.1-pre-scalar-oversight.md`

  Longer LTFF-oriented memo. Frames pale-ale as pre-scalar oversight infrastructure for agentic AI artifact chains.

- `ltff-eoi-v0.2-300w.md`

  Short LTFF EOI draft. Use this as the compressed version for forms, introductions, or first-pass grant discussion.

## Positioning split

Common memo:

- structural telemetry for LLM and agent evaluation artifacts;
- human-review shortlist;
- evaluation / red-team / agent-trace triage.

LTFF memo:

- pre-scalar oversight infrastructure for agentic AI artifact chains;
- scalable oversight;
- safety-case evidence;
- validation and scaling, not ideation.

## Claim boundaries

These outreach documents are first-contact materials. They should keep the
claim surface narrow, practical, and externally legible.

They should describe pale-ale as:

- structural telemetry for LLM and agent evaluation artifacts;
- pre-scalar oversight infrastructure for agentic AI artifact chains;
- a way to produce reproducible shortlists of artifacts or trace rows for
  human-review prioritization;
- bounded artifact-level evidence with a validation and scaling plan.

They should not describe pale-ale as:

- a benchmark;
- a correctness classifier;
- a model-quality ranking system;
- a deception detector;
- a semantic-inconsistency detector;
- a mechanistic claim about model weights.

More speculative mathematical or physical research directions belong in
separate technical notes or internal planning material, not first-contact
outreach memos.

Validation language should remain modest:

- bounded artifact-level evidence;
- preliminary source-facing signal;
- validation readiness;
- rendering / artifact-format ablations;
- multi-annotator checks where feasible;
- baseline comparison against simple triage heuristics.
