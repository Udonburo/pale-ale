# Gate12C-2 legacy boundary

The pre-2026-08-12 Gate12C-2 control plane is retired and intentionally absent
from the curated public tree. It must not be reconstructed as the starting
point for a new run.

The frozen replacement is retained in `gate12c2_minimal/`. See
`../docs/reference/gate12c2_control_plane_sunset.md` for the boundary.
