Scope
-----

The record reproduces exact-law/ordering checks and saved-data tables and
figures. It is not a full archive of all raw observations, bootstrap samples,
timing rounds, or baseline/calibration orchestration. Timing-driver output is
an engineering check and is not substituted for the manuscript observations.

The Zenodo DOI is reserved during preparation and resolves publicly only after
the record is published. Files cite that archival identifier without claiming a
package-containing Git commit. Publication materials and data are CC BY 4.0;
code remains MPL-2.0. See LICENSES.txt.
