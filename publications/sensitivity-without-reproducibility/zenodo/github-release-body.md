## Sensitivity Without Reproducibility

Zenodo DOI: [10.5281/zenodo.22180751](https://doi.org/10.5281/zenodo.22180751)

This technical report separates positive-control sensitivity from fresh
cross-presentation re-estimation for an operator-valued representation
instrument in Qwen models.

Qwen3.5-27B and Qwen3.6-27B qualified for visible overwrite propagation on
one frozen register protocol. A rank-4, three-layer paired-map instrument then
qualified on one bounded Qwen3.6-27B substrate. In a prospectively frozen
20-block requalification, broken-square sensitivity remained detectable in
59/60 layer-blocks, but split-half path-map spectral re-estimation passed in
35/60 and only 5/20 blocks qualified jointly across all three layers. The
required gate was 16/20 with at least four blocks per rollout depth.

Stage E remained unopened, so the representation--function hypothesis was not
tested. The release includes the 13-page DOI-bearing report, buildable LaTeX
source, all 60 continuous Stage M records, model/runtime bindings, provenance
closure, and SHA-256 inventories. Non-code publication materials use CC BY
4.0; bundled Python source uses MPL 2.0.
