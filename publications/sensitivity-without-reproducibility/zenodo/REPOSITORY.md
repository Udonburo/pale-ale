# Repository mirror

This directory is the repository mirror for the version-specific Zenodo
record [10.5281/zenodo.22180751](https://doi.org/10.5281/zenodo.22180751),
as identified in `zenodo-metadata.json`. The DOI-bearing files and their
published hashes are fixed by the final release build.

The matching GitHub release will be anchored after the DOI-bound package is
merged. GitHub remains the development and browsing surface; Zenodo is the
primary archival reference.

The reproducibility capsule contains only public, model-forward-free material.
Private execution artifacts, provider credentials, machine-specific paths,
model weights, and unopened Stage E outcomes are excluded.
