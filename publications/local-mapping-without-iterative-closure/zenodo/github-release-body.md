## Local Mapping Without Iterative Closure

Zenodo DOI: https://doi.org/10.5281/zenodo.21992852

Across prospectively frozen zero-shot and input-output-only in-context
protocols, Qwen3 models up to 8B did not meet the predeclared length-8 parity
criterion. Correct demonstrations yielded a behavioral pass on the two-input
mapping surface in Qwen3-4B and Qwen3-8B, while no correct-demonstration P3
cell met the frozen score-signal criterion at 4, 16, or 64 demonstrations.

The report localizes an observational task boundary between
context-conditioned local mapping and iterative composition. It does not
claim a reusable XOR algorithm, a hidden mechanism, or a result about global
obstruction: the ICL relational-cycle surface, A2-M, decorated-theta B, and
all activation analyses remained unopened by conditional stopping.

The release includes the seven-page DOI-bearing report, TeX source,
capability matrix, public-safe reproducibility capsule, metadata, build
receipt, and SHA-256 inventories. Non-code publication materials use CC BY
4.0; bundled source code uses MPL 2.0.
