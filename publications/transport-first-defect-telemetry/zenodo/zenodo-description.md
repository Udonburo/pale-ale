This formal technical note provides a minimal mathematical formulation of a
transport-first closure-defect readout on replay artifact graphs. It defines
projector-first local objects, directed transport, explicit-cycle closure
defects, and an equal-rank gauge-invariant closure residual, with a rank-aware
partial-isometry appendix.

revise that empirical report, and it does not claim universal inconsistency
detection, graph-wide operators, or field-level aggregation.
