## 0. Scope

This file defines only when opening a graph-wide operator would be honest.

It does not:

- design a connection Laplacian
- open graph-wide smoothing
- introduce field language
- introduce spectral branding
- rescue Gate9A or Gate9B by larger machinery

It does:

- keep graph-wide operator status explicitly closed
- define admission criteria only
- record what remains missing after Gate9B

## 1. Why This Exists

Gate9A showed:

- implementation success
- read immature

Gate9B showed:

- falsifier sharpening success
- explanatory failure

That means the next honest question is not:

- which graph-wide operator to open

It is:

- what must be true before opening any graph-wide operator would be scientifically defensible

Gate9C therefore begins from this sentence:

- graph-wide operator admission must be earned before graph-wide operator design is allowed

## 2. Operator Status

Graph-wide operator status is:

- `not yet opened`

This includes:

- connection-Laplacian-like operators
- graph-wide inconsistency energies
- smoothing operators
- spectral graph operators derived from the present relation graph

No operator may be opened merely because:

- the graph-gauge line is intellectually attractive
- the cycle study feels incomplete
- a larger operator could smooth over current motif weakness

## 3. The Gate9C Question

The Gate9C question is:

- what preconditions must be satisfied before a graph-wide operator can be introduced without becoming a rescue layer

This is an admission question only.

It is not yet:

- an operator-comparison question
- a graph-wide execution question
- a field-aggregation question

## 4. Required Admission Criteria

All of the following are required before graph-wide operator design may begin.

### 4.1 Usable Motif Coverage

The current cycle family must be instantiated often enough on the cells it claims to read.

In practice this means:

- conflict-side motifs cannot remain dominated by `missing_*_anchor`
- cycle availability must cover the proving-ground cells, not only the easiest or cleanest cells
- the graph cannot rely on motifs that are mostly absent where the scientific burden lives

If motif coverage remains sparse or asymmetric, operator opening is denied.

### 4.2 Non-Trivial Anchor-Conditioned Read

The line must possess a non-trivial anchor-conditioned read before graph-wide propagation is allowed.

This does not require the current Gate9A closure observable to be the final form.

It does require:

- anchor-conditioned information is discriminative somewhere that matters
- anchor logic is not functionally dead on the active bundle
- graph-wide operators are not being used to hide the absence of useful anchor-conditioned structure

If anchor-conditioned read remains trivial, operator opening is denied.

### 4.3 Cycle Family Not Dominated By Cleaner Cells

The currently licensed cycle family must stop being dominated by cleaner cells.

In practice this means:

- `cleaner_cell_dominance` cannot remain the main headline outcome of the core support-cycle read
- conflict-side or distributed-incompatibility-side reads must become materially more legible than cleaner-cell reads under the same frozen law

If cleaner cells still dominate the cycle family, operator opening is denied.

### 4.4 Missingness Topology Explicitly Accounted For

Missingness is now a first-class part of the scientific object.

Before graph-wide operators open, the line must explicitly account for:

- missing anchors
- unavailable cycle legs
- coverage asymmetry across cells
- whether absence is structural, taxonomic, or implementation-bound

Missingness must not be silently absorbed into smoothing or spectral machinery.

If missingness topology is not explicit, operator opening is denied.

## 5. Additional Guardrails

Even if the admission criteria begin to improve, the following still remain forbidden at Gate9C admission stage:

- smoothing rescue
- spectral branding
- field language as public headline
- replacing explicit cycle/failure artifacts with one operator score
- using graph-wide machinery to step around Gate9B falsifiers rather than answer them

## 6. What Admission Would Earn

If and only if the admission criteria are satisfied, Gate9C would earn the right to say:

- a graph-wide operator may now be specified without immediately functioning as rescue machinery

That still would not earn:

- operator success
- explanatory settlement
- field ontology
- spectral law

It would earn only:

- permission to design and test a graph-wide operator honestly

## 7. What Denial Means

If the admission criteria are not satisfied, the correct interpretation is not:

- graph-gauge failed

It is:

- the present local cycle family has not yet earned graph-wide escalation

Denial therefore protects the line from:

- premature smoothing
- narrative inflation
- replacing local failure with larger machinery too early
