## 0. Scope

Gate12 is the first theory-construction chapter that follows the Gate11 admissibility membrane freeze.

Gate12 does:

- fix the minimum public doctrine for discrete connection on the repo's inference graphs
- define what counts as a node, an explicit transport relation, an admissible local gauge change, and an explicit cycle holonomy read
- preserve the mainline discipline that projector is public and basis is auxiliary
- keep connection prior to curvature, energy, and action

Gate12 does not:

- draft a runner, schema, smoke handoff, or implementation contract
- define connection Laplacian or any energy functional

- treat bundle, Berry, Yang-Mills, higher gauge, sheaf, or cohomology as the public subject
- reopen operator admission or widen Gate11

## 4. Minimal Ontology

Gate12 public ontology is limited to the following objects.

### 4.1 Node

A `node` is one explicit local site in the inference graph on which one local object may be attached.

Gate12 does not yet require node subtyping beyond explicit graph identity.

### 4.2 Trusted-Tree Edge

A `trusted-tree edge` is one explicit transport-bearing edge that belongs to the preserved trusted-tree line.

### 4.3 Residual-Chord Edge

A `residual-chord edge` is one explicit transport-bearing edge that does not collapse into the trusted-tree line and must remain distinguishable from it.

### 4.4 Anchor Relation

An `anchor relation` is one explicit conditioning relation that may restrict or qualify transport, closure, or comparison without becoming a free global shortcut.

It is not a fourth standalone transport-bearing edge type.

It qualifies an otherwise explicit trusted-tree or residual-chord transport relation.

### 4.5 Local Object

A `local object` is the minimum public object attached to a node and carried by transport.

Gate12 fixes:

- projector is the public identity-bearing local object
- basis data may appear only as auxiliary support for representing the same local projector/span
- rank, local span, and spectral summaries may be recorded only as derived local properties, not as replacements for the projector-level public object

## 5. Transport Discipline

Transport is allowed only if all of the following remain explicit:

- the start node is explicit
- the end node is explicit
- the carrying relation is explicit as a trusted-tree edge or a residual-chord edge, with any anchor-conditioned qualification written separately and explicitly
- the transported public object is still projector-level

Gate12 forbids:

- implicit all-to-all transport
- graph-wide smoothing masquerading as transport
- silent identification of trusted-tree transport with residual-chord transport
- transport rules that exist only as prose without an explicit graph relation

## 6. Gauge Discipline

Gate12 may use `gauge` language only in the following narrow sense:

- an admissible local gauge change preserves the same local projector/span while allowing auxiliary basis replacement or equivalent local reparameterization

Gate12 does not yet claim:

- a full continuum gauge field
- Yang-Mills structure as public doctrine
- higher gauge, sheaf, or cohomology machinery

The public invariant target is therefore:

- projector-level identity
- transport-level compatibility that survives admissible local basis replacement

In the minimum Gate12 sense, `transport-level compatibility` means:

- the public transport judgment between explicit endpoints remains unchanged under admissible local basis replacement of the same projector/span data

## 7. Explicit Cycle Holonomy

Gate12 allows holonomy reads only on explicit finite cycles.

Use `explicit cycle holonomy` only if:

- the cycle is written explicitly as a finite ordered sequence of named edges/relations
- the cycle is closed on the graph as written
- the read remains tied to the same projector-level local objects and explicit transport law
- the read is presented as a curvature-like observable, not yet as an energy or action

Gate12 forbids:

- informal loop language without an explicit cycle
- implicit global closure
- holonomy claims that depend on hidden edges or prose-only transport
