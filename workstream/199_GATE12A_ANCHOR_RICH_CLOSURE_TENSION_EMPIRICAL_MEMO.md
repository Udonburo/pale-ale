## 3. First Empirical Findings

### 3.1 Scalar residual did not behave as a monotone correctness score

The current surface does not support:

- `higher residual => worse answer`

or:

- `lower residual => better answer`

as a tracked public law.

The current surface instead shows:

- sane low-residual closures
- sane high-residual closures
- distortion-sensitive middle-band closures

### 3.2 The current `flat` band was mostly stable conflict-respecting closure

Current first-pass labels for the `flat` band:

- `flat, conflict_respected = 6`

In the present sample, the flat band mostly reads as:

- stable closure that preserves the intended conflict discipline without visible compensatory language

### 3.3 The current `tense` band was the most distortion-sensitive band

Current first-pass labels for the `tense` band:

- `tense, conflict_respected = 2`
- `tense, hypothetical_rejection = 8`
- `tense, phantom_barrier = 2`

This means the middle band is where the current surface most often shows:

- compensatory hypothetical setup-and-rejection
- defensive mention of a barrier or drift not required by the prompt surface
- visible linguistic distortion even when the answer remains locally recoverable

### 3.4 The current `high_tension` band still contained sane closures

Current first-pass labels for the `high_tension` band:

- `high_tension, surface_noise_only = 4`
- `high_tension, support_fused = 2`

This means the highest currently observed residuals did not collapse into obvious failure on the present text surface.

They instead often read as:

- noisy-but-still-sane closure
- direct support-fused closure

### 3.5 Surface phenotype was not fixed by final answer text alone

The current surface already contains a stronger empirical hint:

- the same sample surface may appear in different closure bands under different cycle paths

Current example:

- `sample_000003` appears in both `flat` and `tense`
- the visible answer remains conflict-respecting in both cases

So the current audit suggests:

- final answer surface alone is insufficient to recover the whole closure path

This is a scoped finding about the current Gate12A audit regime, not yet a universal law.
