### 5.1 Explicit Admissible Later-Source Presence Marker Is Present

### 5.2 Later-Source Singularity Is Single

One admissible later source counts as present under the fixed Gate11L path only if:

- exactly one later source is present
- no second competing later source is implicitly or explicitly introduced

- `deferred`

### 5.3 Same-Source Fixed Gate11L Path Is Instantiated

One admissible later source counts as present under the fixed Gate11L path only if the controlling source explicitly states that the same later source carries:

- one explicit `later_source_id` or `later_frozen_run_id`
- one later source and only one later source
- one declaration marker
- one candidate id
- one class
- one explicit host-failure sentence
- matched status, registry, and read surfaces

If those elements are not explicit on the same later source, fixed-path instantiation is not yet established.

### 5.4 Admissibility Boundary Remains Intact

One admissible later source counts as present under the fixed Gate11L path only if:

- shortcut is not needed
- inflation is not needed
- retroactive rewrite is not needed
- graph-wide leap is not needed
- worker-side synthesis is not needed
