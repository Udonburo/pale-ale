# Repository mirror

The twelve top-level publication files in this directory are byte-for-byte
copies of the files published at
[Zenodo DOI 10.5281/zenodo.21992852](https://doi.org/10.5281/zenodo.21992852).
Their published SHA-256 inventory is `CHECKSUMS-SHA256.txt`.

For direct source review on GitHub, the repository additionally expands the
public-safe members of `reproducibility-capsule.zip` under:

- `code/` — runner and figure-generation snapshots;
- `plans/` — prospectively frozen branch plans and the public specification
  excerpt;
- `results/` — exact public branch summaries and cell-level metrics; and
- `bindings/` — runtime/model metadata and the capsule checksum inventory.

These expanded files do not add a new evidence surface. They mirror files
already contained in the published reproducibility capsule. The original
local-only research workspace, machine paths, provider credentials, and
non-public execution artifacts are not part of this repository release.
