the nearest collisions needed to keep the candidate protocol's language

## Bound wording

The candidate may say that it prospectively tests whether one frozen,
gauge-invariant block-level representation feature adds held-out predictive
value for one frozen block-level functional discrepancy on one exact model
revision.

It may not say that raw overlap is a causal transition; that visible-state use
establishes a hidden causal register; that qualification establishes
uniqueness; or that the work is the first use of naturality, holonomy,
intermediate-state edits, causal abstraction, or functional grounding.
