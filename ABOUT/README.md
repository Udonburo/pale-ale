# About pale-ale

`pale-ale` contains research on exact stochastic simulation and the measurement
of learned systems. Start with a published result and its companion; the
numbered research history supplies background when you need it.

## Read a result with its evidence

The publication page identifies the manuscript, release, licensing, and
verification scope. The companion contains the inputs and code needed to
check that result. A tagged release fixes those identities while current
working documentation can improve.

The earlier Gate12A/B/C documents describe bounded structural-replay studies.
They remain useful historical records; the publication catalog also includes
later measurement and Array-RQMC work. The
[forward-directions note](FORWARD_DIRECTIONS.md) records earlier possibilities
rather than a completed result or a current project-wide commitment.
