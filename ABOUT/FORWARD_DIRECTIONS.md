# Forward Directions

This file is intentionally about extension directions, not established results.

The current public Gate12A report is narrow on purpose. Future work should widen the line only in ways that keep the present claims controlled.

## Empirical Extensions

The next empirical extensions split into two different categories.

### Protocol-preserving extensions

These keep the frozen regime unchanged and ask how far the current replay signature survives:

- additional dense-transformer family closures beyond the current 3B/4B core
- more transcript-only supporting lines when full family closure is not yet available
- better public packaging of manifests, checksums, and run-level provenance

### Protocol-expanding extensions

These intentionally change the surface and must stay separate from the mainline:

- architectures that require non-mainline extractor surfaces
- loader stacks that need newer runtime or dependency assumptions
- precision changes, multi-GPU execution, or non-FP32 surfaces

## Mathematical Extensions

The broader mathematical program should be treated as a road ahead, not as something already earned by the current report.

Natural next directions include:

- richer transport formalisms beyond the current fixed overlap/SVD law
- higher-order loop structure beyond triangle compatibility alone
- more explicit relations between trusted-tree backbones and residual-chord tension structure
- cleaner bridges from the artifact-level replay surface back to local mechanistic evidence

## Publication And Documentation Extensions

The repo should also get easier to read from the outside.

That means:

- a dedicated paper source surface once the report is frozen
- clearer top-level release notes mapping paper, artifacts, and implementation snapshots
- concise visual summaries for the Gate12A regime, archive high-tension convergence, and boundary outcomes

## Constraint

The key rule is simple: future ambition should not be allowed to rewrite current evidence.

The current report earns a narrow frozen-regime claim. Future empirical and mathematical work can extend that line, but it should do so by adding new explicit surfaces, not by making the existing claim blurrier.
